# House-Price-Prediction
# 🏠 House Price Prediction using Linear Regression

## 📌 Description
A simple Machine Learning project that predicts house prices using **Linear Regression**.
The project uses a small manually created dataset containing house characteristics to train a regression model and predict prices.
## 📊 Dataset Features
- **Area:** House area (m²)
- **Bedroom:** Number of bedrooms
- **Bathroom:** Number of bathrooms
- **Age:** House age (years)
- **Price:** House price (Target)

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
## 🤖 Model
Linear Regression

## 🎯 Goal
To understand how Linear Regression works and how house prices can be predicted based on property features.
